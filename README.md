# Xehomnay

Foundation for Xehomnay, a single Next.js App Router application using a modular monolith and feature-based source layout.

## Getting started

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env` when configuring local environment values.
3. Run `npm run dev`.

Database setup and authentication flows are intentionally not configured yet. See [docs/architecture.md](docs/architecture.md).
