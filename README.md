# xehomnay

Dự án thuê xe được xây dựng với Next.js App Router, TypeScript và Tailwind CSS.

## Bắt đầu

```bash
yarn install
yarn dev
```

Mở [http://localhost:3000](http://localhost:3000) để xem ứng dụng.

## Lệnh Yarn

- `yarn dev`: chạy máy chủ phát triển
- `yarn build`: tạo bản build production
- `yarn start`: chạy bản production
- `yarn lint`: kiểm tra ESLint
